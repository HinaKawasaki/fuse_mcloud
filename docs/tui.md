# 首次设置 TUI 设计

> 目标：让第一次使用的人**不需要读 README、不需要记参数**就能完成安装。
> 实现模块：`mcloud_fuse/tui.py`（通用组件）+ `mcloud_fuse/setup.py`（流程）。

## 设计原则

1. **一次只问一件事**：7 步，每步一个决定；`Esc` 可以回退，不丢已经填的内容。
2. **默认值就是推荐值**：一路 `Enter` 也能完成设置，结果是一个可用的挂载。
3. **不显示秘密**：token 粘贴时暂时退出界面（正常终端回显），只展示脱敏账号与到期时间。
4. **不依赖第三方 TUI 库**：只用标准库 `curses`，少一个会让 `pip install` 变重的依赖。
5. **一定有降级路径**：非 TTY / `--no-tui` / `--yes` 走行模式，脚本与 CI 不经过 curses。
6. **失败也要能看懂**：每一步执行结果用 `[OK] / [!] / [!!]` 标注，不在界面里抛 traceback。

## 流程

```text
欢迎 / 风险确认
   └─(Esc/q 退出)
      ↓
1 访问令牌 ── 已有有效 token？ ── 是 → 使用 / 重新粘贴
      ↓                          └ 否 → 退出 curses 粘贴 → 校验 → 失败重试
2 挂载点（输入，校验绝对路径、可创建、可写、未挂载）
      ↓
3 云盘范围（菜单：整个云盘 / 指定 fileId）
      ↓
4 缓存目录（输入，禁止与挂载点互相包含）
      ↓
5 删除方式（永久删除 / 回收站）
      ↓
6 覆盖写冲突（保留副本 / 报错）
      ↓
7 启动方式（systemd --user / 仅保存配置）
      ↓
确认页（摘要）── 开始执行 / 重新配置 / 退出
      ↓
执行页（保存 token → 写配置 → 验证账号 → 安装服务）
      ↓
完成页（结果列表 + 下一步命令）
```

### 2. 访问令牌

已有有效 token 时先给选择：

```text
┌ 访问令牌 ───────────────────────────────────────────── 步骤 1/7 ┐
│  令牌等同于账号访问权，只保存在本机 0600 文件里；向导不会显示明文。 │
│                                                                │
│  › 使用已保存的令牌                                            │
│    账号 138****8000；2026-12-02 到期（剩余 29.8 天）           │
│    重新粘贴令牌                                                │
│    从浏览器重新复制 Authorization，或整段 cURL                 │
│                                                                │
│  ↑↓ 选择   Enter 确认   Esc 上一步   q 退出                    │
└────────────────────────────────────────────────────────────────┘
```

选择“重新粘贴”会**暂时退出 curses**，打印操作步骤，等待粘贴到 `Ctrl-D`：

```text
请先在浏览器里拿到 token：
  1. 打开 https://yun.139.com/ 并确认已登录
  2. 按 F12 → Network → 过滤 file/list → 点任意一条请求
  3. 右侧 Request Headers → 复制 `Authorization: Basic ...` 整行
     （或右键该请求 → Copy → Copy as cURL）

粘贴到下面，按 Ctrl-D 结束；直接 Ctrl-D 表示跳过。
```

校验失败不会退出向导，而是回到粘贴页并给出原因（Cookie、base64 非法、已过期）。

### 3. 挂载点

```text
┌ 挂载点 ─────────────────────────────────────────────── 步骤 2/7 ┐
│  云盘内容会出现在这个目录；目录不存在时会自动创建。             │
│                                                                │
│  > /home/you/mnt/mcloud_                                       │
│    ────────────────────────────────────────────────            │
│  提示：如果目录里已有文件，挂载后会被暂时遮住，原文件不会被删除。 │
│                                                                │
│  Enter 下一步   Ctrl-U 清空   Esc 上一步                       │
└────────────────────────────────────────────────────────────────┘
```

校验规则（`setup.validate_mountpoint`）：

- 非空、绝对路径（`~` 会被展开）；
- 不能是 `/`；
- 不能已经是挂载点；
- 能创建、当前用户可读写执行。

### 5. 缓存目录

```text
┌ 缓存目录 ───────────────────────────────────────────── 步骤 4/7 ┐
│  大文件按需读取与写回上传都依赖它；不要放在挂载点里面。          │
│                                                                │
│  > /tmp/cmcloud-fuse_                                          │
│    ────────────────────────────────────────────────            │
│  tmpfs，读缓存与待上传文件都放这里；日志单独持久化。可用 1.9 GiB。│
│                                                                │
│  Enter 下一步   Ctrl-U 清空   Esc 上一步                       │
```

校验规则：绝对路径、可创建可写、**不能和挂载点互相包含**（否则会递归，
或卸载时误删缓存）。

## 按键

| 页面 | 按键 | 行为 |
| --- | --- | --- |
| 菜单 | `↑` / `k`、`↓` / `j` | 移动选择 |
| 菜单 | `Enter` / `空格` | 确认 |
| 菜单 | `Esc` | 上一步（欢迎页为退出） |
| 输入 | 可打印字符 | 插入 |
| 输入 | `Backspace` / `Delete` | 删除 |
| 输入 | `←` / `→` / `Home` / `End` | 移动光标 |
| 输入 | `Ctrl-U` / `Ctrl-W` | 清空到行首 / 删除前一个词 |
| 输入 | `Enter` | 校验并下一步 |
| 任意 | `Ctrl-C` | 立即退出（不写配置） |
| 任意 | `q` | 退出（完成页除外） |

## 降级与兼容

| 条件 | 行为 |
| --- | --- |
| stdin/stdout 不是 TTY | 自动走行模式，不初始化 curses |
| `--no-tui` | 强制行模式 |
| `--yes` / `-y` | 行模式 + 全部默认值（仍要求 token） |
| `--token-stdin` | 从标准输入读 token，适合自动化 |
| `TERM` 不可用 | `tui.run` 抛 `TuiUnavailable`，回退行模式 |
| 终端小于 60x16 | 显示提示并等待调整，不直接崩溃 |
| 没有颜色 | `attr()` 退化为 `A_BOLD` / `A_REVERSE`，布局不变 |

行模式与 TUI 共用同一套 `SetupPlan`、校验函数与 `execute()`，不会出现
“向导能过、脚本不能过”的双重标准。

## 错误处理

- **令牌错误**：回到粘贴页，给出 Cookie / base64 / 过期三类明确提示。
- **路径错误**：留在当前输入页，错误信息显示在输入框下方，不清空已输入内容。
- **写配置失败**：执行页标记 `[!!]` 并停止后续步骤（服务不会安装）。
- **账号验证失败**：标记 `[!]` 警告但继续；配置已保存，可稍后 `doctor`。
- **服务安装失败**：标记 `[!]` 警告；配置保留，提示手动 `mcloud-fuse`。
- 向导不打印 traceback，也不把 token 写进异常信息。

## 代码结构

```text
mcloud_fuse/
├── tui.py          # Screen：边框、菜单、输入、消息、进度、宽度/折行/行编辑
├── setup.py        # 流程状态机、7 步页面、校验、行模式、execute()
├── userconfig.py   # config.json 的读写与 0600、环境变量注入
├── tokens.py       # token 解析/脱敏/落盘（脚本与向导共用）
└── service.py      # systemd --user 单元生成、安装、状态
```

`tui.py` 里可测试的纯逻辑（`display_width`、`clip`、`wrap_text`、`LineEditor`、
`visible_field`）与 curses 渲染分离；CI 不需要 TTY 就能覆盖这些部分。
